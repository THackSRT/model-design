# Notices de tiers : moteur patterning

Les tracés des jupes (et ceux qui suivront) sont réécrits en Python pur à partir des constructions de
**GarmentCode**, utilisé comme référence de conception (ADR 0010). Aucun code de GarmentCode n'est copié ni
installé ; chaque module réécrit cite son fichier d'origine (commit `d449629`) dans sa docstring.

Projet : <https://github.com/maria-korosteleva/GarmentCode>
